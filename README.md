## 💡 What is this?

Ever reported a broken road or a garbage pile-up and just... never heard back?

**Citizen Complaint Portal** fixes that. Citizens report civic issues in under a minute. Officers track, manage, and resolve them — with full transparency for everyone. 🌉

---

## ✨ Highlights

- 📝 **Report in seconds** — title, category, area, done.
- 🔁 **No duplicates** — smart detection nudges you to upvote instead of re-filing.
- 👍 **Upvote power** — popular issues rise to the top.
- 🚦 **Auto priority badges** — Low → Medium → High → Critical, calculated automatically.
- 🤖 **AI daily briefing** — officers get a smart, plain-English summary every morning.
- ⭐ **Feedback loop** — citizens rate resolutions, officers stay accountable.
- 📤 **One-click CSV export** — for real government reporting.

## 🚀 Quick Start

```bash
git clone https://github.com/<your-username>/citizen-complaint-portal.git

cd server && npm install && npm run dev
cd client && npm install && npm run dev
```

Add your `.env`:
```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
CLAUDE_API_KEY=your_claude_key
```
